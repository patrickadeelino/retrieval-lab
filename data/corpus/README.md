# Pilot corpus: Portuguese GitHub Docs

This snapshot contains six pages from the official Portuguese GitHub Docs and 53 extracted chunks. `pages.jsonl` stores the frozen source text; `chunks.jsonl` is the retrieval unit; `manifest.json` records source URLs, collection time, and SHA-256 hashes of the fetched HTML. Run `python scripts/build_corpus.py` to rebuild chunks from the frozen pages. The `--refresh` option replaces the snapshot with the current website and may change chunk IDs and results; review the diff before accepting an update.

Extraction keeps article text under its section headings, removes navigation, long code examples, and further-reading lists, then groups paragraphs or list items into chunks of approximately 1,600 characters or fewer. Chunk IDs are stable within this snapshot. Inspect the chunks before judging relevance; the pilot judgments are in [`../qrels/pilot-proposed.jsonl`](../qrels/pilot-proposed.jsonl).

Source: [Portuguese GitHub Docs](https://docs.github.com/pt), © GitHub, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The text was selected from the source pages, extracted, and chunked. The `github/docs` repository [identifies the documentation as Creative Commons content](https://docs.github.com/pt/get-started/exploring-projects-on-github/contributing-to-open-source); its [package metadata](https://github.com/github/docs/blob/main/package.json) lists CC-BY-4.0 alongside the code license. This project's code and source texts have separate provenance.

GitHub notes that [some Portuguese content may be machine-translated](https://docs.github.com/pt/webhooks/using-webhooks/best-practices-for-using-webhooks). When judging an ambiguous passage, compare it with the original English page. The pilot queries are in [`../queries/pilot-queries.jsonl`](../queries/pilot-queries.jsonl).
