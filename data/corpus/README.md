# Pilot corpus: Portuguese GitHub Docs

This snapshot contains six pages from the official Portuguese GitHub Docs and 50 extracted chunks. `pages.jsonl` stores the frozen source text; `chunks.jsonl` is the retrieval unit; `manifest.json` records source URLs, collection time, and SHA-256 hashes of the fetched HTML. Run `python scripts/build_corpus.py` to rebuild chunks from the frozen pages. The `--refresh` option replaces the snapshot with the current website and may change chunk IDs and results; review the diff before accepting an update.

Extraction keeps article text under its section headings, removes navigation, long code examples, and further-reading lists, then groups paragraphs or list items using only the 512-token budget from the pinned `intfloat/multilingual-e5-small` tokenizer. Token counts include the `passage:` prefix and special tokens, with truncation disabled. A single indivisible segment that exceeds the token budget is kept in its own chunk and is skipped individually by the indexer. The corpus manifest records the tokenizer revision and limit. Chunk IDs are stable within this snapshot. The current token-only snapshot has 50 chunks. The baseline qrels are complete for this snapshot; changed judgments were adjusted where identified, while some grades were carried forward from the earlier 53-chunk snapshot (see [`../qrels/README.md`](../qrels/README.md)).

This project's code and source texts have separate provenance.

GitHub notes that [some Portuguese content may be machine-translated](https://docs.github.com/pt/webhooks/using-webhooks/best-practices-for-using-webhooks). When judging an ambiguous passage, compare it with the original English page. The pilot queries are in [`../queries/pilot-queries.jsonl`](../queries/pilot-queries.jsonl).
